# ADR 0002: 本機可續跑課程任務與分批講義生成

Status: Accepted
Date: 2026-10-21

## Context

使用者希望睡前交付影片，隔天能讀講義與待核對清單。原流程需要助手手動串接，沒有持久任務狀態；中斷可能重做模型工作。原稿不可覆寫，資工模型必須經 run.py，且 GPU 階段不可並行。

## Decision

- 用獨立本機 CLI／背景程序，不依賴聊天 turn 的生命週期。每個任務在被忽略的 output/jobs/ID 內保存輸入、狀態、事件、日誌與產物；不引入資料庫或 Windows 服務。
- 狀態 JSON 原子替換；完成階段記錄產物 hash。續跑先核對，遇到外部修改停止，保留原稿及修訂。轉錄先在暫存成功後才保存原始逐字稿。
- 跨程序 OS 鎖涵蓋整個模型工作及清理，依序使用 Whisper 與本機 Ollama。finally 嘗試停止專案 Ollama，清理失敗不宣稱完成。
- 視覺預設 MiniCPM-V 8B，講義用專用 Qwen2.5 7B 文字模型，以有限大小的來源批次產生結構化 JSON。每批校驗來源 ID 的完整分組，保存 checkpoint；數字更動與大幅原句重寫不接受，矛盾與校正另存。沿用共用閱讀器，不經舊的範例專用 L2/L3 匯出器。

2026-10-21 修復補充：不安全的校字只拒絕該建議，保留原句並將受影響的講義段落換成明示待核對的原句，避免未確認的推論流入正文，同時不阻塞其餘課程內容。來源／格式無法驗證的回應仍須重試或失敗。VLM 的中途與最後存檔均透過專案轉接層重試 Windows 暫時分享鎖。
- 保留每個抽樣 PNG，只合併相鄰像素完全相同的畫面；回頁仍是新的出現區間，僅相同像素共用視覺分析。避免近似去重把註記變化抹掉。

## Consequences

- 同一命令可啟動、觀察、續跑，完成階段可重用，私有課程不混入公開 demo。
- 不需要雲端憑證或按次 API 費用；新增文字模型約需 4.7 GB 磁碟空間。講義品質仍需抽查，來源覆蓋不等於語意正確。
- 壓縮雜訊可能產生很多區間，增加時間與磁碟用量；兩秒抽樣仍可能漏掉短暫切頁。
- 斷電／硬終止不能保證 finally，需手動續跑或停止專案 Ollama。尚未提供自動開機續跑或多課程排程。

## Alternatives considered

- 依靠聊天助手保持整晚活躍：沒有可靠的程序生命週期及可重跑的講義介面。
- 雲端 LLM 作為預設：可能提升品質，但目前沒有已確認的 API 憑證、傳輸範圍及費用設定。
- 單用既有 MiniCPM-V 看圖及寫講義：短片試跑出現格式範例抄寫、錯誤來源引用與不忠實校正，不能作為預設文字生成器。
- 任務資料庫／常駐服務：有利佇列與多使用者管理，現階段單機單 GPU 任務先保留簡單檔案介面。
- 近似畫面去重：較快，但會將細小板書或註記當成相同；首版優先保存證據。
