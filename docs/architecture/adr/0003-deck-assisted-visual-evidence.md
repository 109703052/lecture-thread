# ADR 0003: 原始投影片與影片出現紀錄分層

Status: Accepted
Date: 2026-10-28

## Context

兩秒抽樣加像素完全一致去重，讓同一頁的微小差異觸發大量 OCR／視覺推論。使用者提供原始 PPTX，要求投影片為主軸、手寫為補充，並先驗證較疏取樣。原始檔也包含動畫；匯出的最終頁不能代表影片每個時刻的狀態。

## Decision

- 原始投影片文字、圖表與頁面身分作為可共用基準；影片出現時間、回看、動畫及註記版本另存。來源檔與呈現用 PDF 都記錄 hash，版本不同不得混用快取。
- 先以五秒候選畫面做頁面配對，不等於五秒一次模型推論。換頁邊界與局部變化須另驗證；既有兩秒證據不刪除或覆寫。
- 配對保留排名、幾何證據及 ambiguous/unmatched 狀態，不用單向頁碼假設強迫消除回看或相近動畫頁。
- 完全相同圖片共用分析。近似圖片只能共用已確認的頁面基準，不得將局部變化宣告不存在；局部辨識上線前須驗證小符號、擦除、動畫與短暫切頁。
- 新對齊結果先作獨立候選層，驗證前不替換正式來源證據。課程可獨立驗證與出版，不需等待整批課程。

## Consequences

- 可避免重複辨識原始投影片文字，保留老師實際講解順序。
- 需要原始檔版本管理、動畫狀態與不確定配對的審閱；幾何配對分數不等於內容正確率。
- 沒有原始檔或版本不符時仍需影片辨識。五秒取樣本身不能保證捕捉短暫畫面。

## Alternatives considered

- 繼續逐張全圖 OCR：可沿用既有產物，但重複成本高且未利用原始檔。
- 只改成更長固定間隔：容易漏掉短暫畫面，不能單獨採用。
- 用原始投影片取代影片畫面：會抹去現場修改和動畫尚未展開的狀態。
