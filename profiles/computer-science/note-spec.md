# 資工課程筆記規格

本規格取代上游醫學筆記格式；不是 Clinical Pearls、臨床診斷或治療排序。

每個投影片出現區間都要有筆記，包含目錄、重複出現與結尾頁。去重只能節省辨識，不得刪除講解。

每頁輸出：
1. 投影片圖片、原文標題、影片起訖時間。
2. 本頁重點：回答這一頁要解決什麼問題。
3. 講師說明：依逐字稿整理因果、操作步驟、條件、例子與權衡，不自行刪除反例。
4. 教學脈絡（推論）：明確標示根據前後講解推論的銜接。
5. 補充與待核對：與講師原話分開；術語校對註明依據，不把不確定的數字改成確定事實。
6. 可回看的來源時間；逐字稿保持原始內容。

全課總覽：以「核心問題 → 分段推進 → 最後結論」整理，附可回看的代表時間。

資工特別規則：
- 保留英文專有名詞、符號、單位、假設及程式碼結構。
- 區分位元 bit 與位元組 byte；數字不一致時公開指出，不能默默更正。
- 區分 I/O 完成通知（interrupt / polling）、定址（port-mapped / memory-mapped）、資料搬移（CPU / DMA）。
- 不把示意圖中的一個硬體例子寫成所有架構的通則。
- 不把低 keyword overlap 當作講師略過；不根據圖像就聲稱知道講師意圖。
- 整理稿以繁體中文撰寫；原始轉錄的簡繁混合不直接覆寫。
- 外部補充若需要精確技術依據應另附來源；本輪優先用投影片及講稿能支持的解釋。

驗收：每個出現區間都有筆記與圖片；所有逐字稿片段有主要歸屬（跨頁片段可在鄰頁作上下文）；回看時間不超出影片；無醫學標籤；已知誤聽及內容矛盾有清單。


## 閱讀優先與逐字稿校正（使用者修訂）

- 總整理必須是可獨立閱讀的講義。沿講師順序直接講清楚問題、概念定義、機制／因果、例子與條件、取捨和結論，避免只寫「老師提到／老師介紹」的內容索引。
- 每個實質講解段落附來源時間，讀者不必先看影片即可理解，再按段落回看。短暫轉場只說明銜接，不捏造詳細內容。
- 預設逐字稿顯示依投影片和上下文校正的閱讀版。原始 ASR 保存在 transcript.json；校正版 transcript.corrected.json；逐句修訂及依據 transcript.corrections.json。
- 校正保持片段順序、起訖時間及原意；可確認的專業術語直接改正，不只在筆記註腳提醒。無法確定的原詞與數值在原句旁標示待核對，不以常識偷偷改成標準答案。
- 不宣稱已聽音確認實際僅依上下文校正的內容。數字矛盾、講師口述與投影片的矛盾仍需保留。
